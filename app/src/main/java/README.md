# CodeAlpha_FitnessTrackerApp

An Android Fitness & Activity Tracker developed as part of the CodeAlpha Android Development Internship.

## Features
- **Activity Logging:** Log various workouts including Walking, Running, Cycling, and Yoga.
- **Calorie & Step Counter:** Automatically computes estimated calorie expenditure and tracks total steps.
- **Persistent Storage:** Uses Android SharedPreferences to retain activity history between sessions.
- **Material Dashboard:** Clean summary card displaying daily metrics.

## Tech Stack
- **Language:** Java
- **UI:** Android XML / Material CardView / ScrollView
- **Storage:** SharedPreferences
- **IDE:** Android Studio
